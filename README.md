# Neural Playground

> Make neural-network behavior something you can experiment with.

**Exploration lab** • **HTML, CSS, JavaScript** • **Read the code, test the assumptions**

---

## The idea

Train a small multilayer neural net from scratch on nonlinear decision boundaries in your browser.

## Run the experience

```bash
python -m http.server 8000
```
Open **http://localhost:8000/**.
